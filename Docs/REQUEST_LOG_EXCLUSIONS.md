# 요청 문서 기록 제외 기준

다음 변경은 [요청 문서](REQUESTS.md)에 별도 요청으로 기록하지 않습니다.

## 사소한 수치 조정

기존 기능이나 구조를 바꾸지 않는 작은 값 조정입니다. 예: 버튼의 여백·크기, 글자 크기, 색상 값, 기존 파라미터의 미세 조정.

## 레벨 내 사소한 배치 조정

동일 레벨에서 기존 액터나 오브젝트의 위치·회전·크기를 조금 조정하는 작업입니다. 예: 소품을 약간 옮기거나 기존 배치의 간격을 정리하는 변경.

## 기록해야 하는 경우

- 기능 추가·삭제·동작 변경, 레벨 구성 변경, UI 흐름 변경, 프로젝트 구조 변경, 작업 지침 변경은 기록합니다.
- 수치나 위치를 바꾸더라도 기능 또는 구조에 영향을 주는 변경이면 단순 조정으로 제외하지 않습니다.
- 사용자가 명시적으로 기록을 요청한 내용은 위 제외 대상에 해당해도 기록합니다.

이 기준은 요청 문서의 기록 범위만 정합니다. 변경 작업과 필요한 검증을 생략하는 기준은 아닙니다.
